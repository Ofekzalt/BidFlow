# Architecture Decision Records

ADRs capture significant decisions that are not already mechanically determined by the approved PRD.

## Format

```text
# NNNN — Decision title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context
## Decision
## Alternatives
## Consequences
```

Number records sequentially using `NNNN-short-kebab-case-title.md`. Accepted records are immutable; create a superseding ADR when a decision changes.

Create ADRs only for significant decisions that need durable context beyond module documentation.
